# Fedja JSON

de.fedjapost.json


## Description

Fedja JSON is a minimal JSON implementation as API for Java 8+.
Its purpose is to provide an easy way to deserialize, mutate and serialize JSON.
The API can be deployed for basically any purpose, such as for JSON-based configuration files or network payloads, without bloating application size.

## How to use

Add the compiled source, for example the `jar`, to the classpath and read the documentation in the `javadoc` folder.
